## 概述

RFX1 是一款 433.92MHz OOK 无线接收模块，用于接收 EV1527 编码的射频信号。与传统的裸接收头方案不同，RFX1 将射频接收、EV1527 解码和帧滤波全部在模块内部完成：主机只需通过 I2C 总线读取，即可拿到稳定的按键帧，无需自己处理高频信号采样、时序解码和重复帧去重等工作。

模块内置 6 档接收速率档位（2.4k / 4.8k / 9.6k / 19.2k / 30k / 40k bps，均为 433.92MHz），用于匹配不同类型的发射端，市面上标注"433"的锂电池类遥控器、自发电开关等设备一般均可接收（速率档位可通过一次简单实测快速确定，详见使用说明）。同时模块自带基于时间窗口的帧滤波功能，能够剔除发射突发造成的重复帧、噪声帧和误码帧，直接输出稳定按键帧；调试阶段也可以读取原始帧，便于观察射频链路质量。

模块默认 I2C 地址为 0x45，并可通过模块背部的地址配置触点调整地址，方便多个模块共存于同一条 I2C 总线。接入时只需连接电源和 I2C 两条线，即插即用，非常适合遥控接收、无线开关、智能家居触发等应用场景。

> 说明：RFX1 仅覆盖接收端。发射端需使用 433.92MHz OOK EV1527 编码的设备（如配套遥控器、自发电开关等）。射频领域俗称的"433"，指的就是 433.92MHz 频段，两者是同一个频段，本文统一写作 433.92MHz。

## 模块参数

- 工作电压：5V

- 接 口：PH2.0 4PIN

- 通信协议：I2C

- 默认 I2C 地址：0x45

- 可配置 I2C 地址范围：0x45 ~ 0x4C（通过背部地址配置触点点焊设置）

- 接收频率：433.92MHz

- 调制方式：OOK

- 解码协议：EV1527

- 接收速率档位：2.4k / 4.8k / 9.6k / 19.2k / 30k / 40k bps

| 引脚名称 | 描述        |
| -------- | ----------- |
| G        | GND地线     |
| V        | 5V电源引脚  |
| SDA      | I2C数据引脚 |
| SCL      | I2C时钟引脚 |

## 使用说明

### 什么是按键帧（按键码）

按下遥控器上的按键后，发射端会向外发送一帧或连续多帧 24bit 的**按键帧**（市面上也常称为**按键码**）。RFX1 接收到这些按键帧后，主机即可通过 I2C 总线从 RFX1 读出。每个按键帧是一个 24bit 的数值，通常用十六进制表示（例如 `0x2E63C2`），对应某个按键的一次触发。

以市面上最常见的 EV1527 编码遥控器为例，按键帧在遥控器出厂烧录时就已确定：帧的**高 20 位是随机生成的地址码**，用于区分不同的遥控器；**低 4 位是固定的按键值**，对应遥控器上的具体按键。也就是说：

- 同一支遥控器的同一个按键，每次发出的按键帧是固定不变的；
- 同一款遥控器的不同个体（包括不同批次生产的个体），地址码互不相同；
- 不同款遥控器之间，地址码同样互不相同。

地址码是遥控器出厂时固化在芯片中的随机识别码：生产时经滚码烧录工艺逐台随机生成并写入，此后不再改变。每台遥控器的地址码互不相同，形成"一机一码"的唯一标识——接收端正是依靠地址码来区分不同的遥控器，避免彼此的按键帧相互串扰。也因此，每台遥控器的按键码都需要实际读取获得，用所选平台库的示例程序即可轻松完成记录。

### 使用流程

在编写主机端逻辑之前，建议先按以下步骤用主机读取并记录遥控器的按键帧：

1. **连接模块**：将 RFX1 按引脚说明接到主控板的 I2C 总线，并准备好遥控器等发射端设备。
2. **运行读取程序**：选择你熟悉平台的 RFX1 库，运行其示例程序，通过串口观察模块输出的按键帧。接收档位与发射端速率的匹配方法，详见下文"接收速率档位（Profile）的选择"。
3. **记录按键帧**：依次按下遥控器上的各个按键，把串口打印出的按键帧逐一记录下来，例如：

   ```text
   A键 → 0x2E63C2
   B键 → 0x2E63C4
   C键 → 0x2E63C8
   ```

4. **编写主机逻辑**：将记录下来的按键帧作为判断依据，在主机程序中匹配帧值并执行相应动作，例如收到 `0x2E63C2` 就点亮 LED、收到 `0x2E63C4` 就启动电机。

完成按键帧的记录后，再进入正式的逻辑开发，所用平台库的安装与用法请参见下文对应章节。

### 接收速率档位（Profile）的选择

RFX1 内置 6 档接收速率档位（2.4k / 4.8k / 9.6k / 19.2k / 30k / 40k bps，均为 433.92MHz），通过选择档位来适配不同速率的发射端：档位与发射端速率一致时即可正常收帧，因此上手的第一步就是为手中的遥控器选好档位。档位通过所用平台的库进行设置（例如 Arduino 库示例中的 `SetRfProfile()`，具体用法见库的使用说明）。

市面上只标注"433"的遥控器，一般指 433.92MHz 频段，RFX1 通常都可以接收，不同类型发射端的常见档位如下：

| 发射端类型 | 常见速率档位 | 说明 |
| ---------- | ------------ | ---- |
| 锂电池类遥控器 | 2.4 kbps（常见） | 市面上大多数标注"433"的遥控器 |
| 自发电开关 | 9.6 kbps、30 kbps（常见） | 波特率比普通遥控器更高 |
| 其他未知发射端 | 逐档试出 | 4.8k / 19.2k / 40k 档供实际测试选择 |

RFX1 提供 6 档接收速率，正是为了覆盖市面上各类发射端的速率差异。上手只需一次简单的实测：连上模块后从低到高逐档尝试，为手中的遥控器选出收帧最稳、距离最合适的档位；再用所选平台库的示例程序读取并记录遥控器各按键的按键码。完成"选档位、记按键码"这两步，就得到了一套贴合实际遥控器的接收配置，后续应用开发即可基于这套配置稳定进行。

档位选择建议（与库的使用说明一致）：

1. 不知道发射端参数时，从最低档 `2.4 kbps` 开始逐档向上尝试，保留**能稳定收帧且满足距离要求的最小档位**；
2. 更高档位通常也能接收更低速率的信号，但有效距离和抗噪表现以实测为准；
3. 误码较多时优先尝试降低档位，让解调参数与发射端速率更贴合。
