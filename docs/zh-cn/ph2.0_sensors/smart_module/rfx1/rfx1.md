## 概述

RFX1 是一款 433.92MHz OOK 无线接收模块，用于接收 EV1527 编码的射频信号。与传统的裸接收头方案不同，RFX1 将射频接收、EV1527 解码和帧滤波全部在模块内部完成：主机只需通过 I2C 总线读取，即可拿到稳定的按键帧，无需自己处理高频信号采样、时序解码和重复帧去重等工作。

模块内置 6 档接收速率档位（2.4k / 4.8k / 9.6k / 19.2k / 30k / 40k bps，均为 433.92MHz），可以匹配不同类型的发射端，常见的锂电池类遥控器、自发电开关等发射设备均可适配。同时模块自带基于时间窗口的帧滤波功能，能够剔除发射突发造成的重复帧、噪声帧和误码帧，直接输出稳定按键帧；调试阶段也可以读取原始帧，便于观察射频链路质量。

模块默认 I2C 地址为 0x45，并可通过模块背部的地址配置触点调整地址，方便多个模块共存于同一条 I2C 总线。接入时只需连接电源和 I2C 两条线，即插即用，非常适合遥控接收、无线开关、智能家居触发等应用场景。

> 说明：RFX1 仅覆盖接收端。发射端需使用 433.92MHz OOK EV1527 编码的设备（如配套遥控器、自发电开关等）。关于 EV1527 帧格式、为什么按一次键会收到多帧等基础知识，可参阅 [什么是 EV1527 帧](https://github.com/nulllab-arduino/nulllab-wiki/tree/main/ev1527_frame)。

## 模块参数

- 工作电压：5V

- 接 口：PH2.0 4PIN

- 通信协议：I2C

- 默认 I2C 地址：0x45

- 可配置 I2C 地址范围：0x45 ~ 0x4C（通过背部地址配置触点点焊设置）

- 接收频率：433.92MHz

- 调制方式：OOK

- 解码协议：EV1527

- 接收速率档位：2.4k / 4.8k / 9.6k / 19.2k / 30k / 40k bps

| 引脚名称 | 描述        |
| -------- | ----------- |
| G        | GND地线     |
| V        | 5V电源引脚  |
| SDA      | I2C数据引脚 |
| SCL      | I2C时钟引脚 |

## I2C地址调整

模块默认 I2C 地址为 0x45。模块背部设有 3 组地址配置触点（对应地址偏移 +1 / +2 / +4），通过点焊连接相应触点来调整 I2C 地址，用于多个模块接入同一条 I2C 总线时的地址冲突处理。

### 配置方法与地址对应关系

| 点焊触点组合        | I2C 地址        | 说明                   |
| ------------------- | --------------- | ---------------------- |
| 不点焊任何触点      | **0x45 (默认)** | 所有触点悬空时的地址   |
| 只点焊 +1 触点      | 0x46            | 焊接 +1 触点期间生效   |
| 只点焊 +2 触点      | 0x47            | 焊接 +2 触点期间生效   |
| 同时点焊 +1 和 +2   | 0x48            | 同时焊接两个触点生效   |
| 只点焊 +4 触点      | 0x49            | 焊接 +4 触点期间生效   |
| 同时点焊 +4 和 +1   | 0x4A            | 同时焊接两个触点生效   |
| 同时点焊 +4 和 +2   | 0x4B            | 同时焊接两个触点生效   |
| 三个触点全部点焊    | 0x4C            | 全部焊接时生效         |

### 注意事项

1. 点焊配置属于永久性改动：焊接前请先确认总线上的地址占用情况，避免与其它 I2C 设备冲突。
2. 地址调整后，主机侧构造对象时需传入对应的新地址（详见下方库的使用说明）。
3. 若不需要修改地址，请保持触点悬空，使用默认地址 0x45。

## Arduino使用

RFX1 的 Arduino 库为 `nulllab_rfx1`，库的安装方式、API 说明、完整示例代码与常见问题排查，请直接参阅库的使用说明：

<a href="https://gitee.com/nulllab-arduino/rfx1_arduino_lib#nulllab-rfx1-arduino-lib" target="_blank">nulllab_rfx1 库使用说明（Gitee）</a>

> 提示：该库依赖 cyfney-cpp 基础库（5.3.0 及以上版本），安装本库时请一并安装。首次使用建议从示例程序入手，收不到帧时优先检查接收速率档位是否与发射端匹配。
